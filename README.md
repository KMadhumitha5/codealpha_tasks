# CodeAlpha Data Analytics Internship – Tasks 2 & 3

**Intern:** Kondam Madhumitha  
**Project:** Student Performance Analysis  
**Tasks:** Task 2 – Exploratory Data Analysis (EDA) and Task 3 – Data Visualization

## Objective
This project analyzes student performance data to identify patterns related to study time, absences, gender, parental education and final grades.

## Tools
Python, Pandas, NumPy, Matplotlib and Seaborn.

## Dataset
UCI Student Performance dataset. The Python script downloads the dataset automatically from the UCI repository when executed.

## Analysis included
- Dataset dimensions and structure
- Data types
- Descriptive statistics
- Missing-value check
- Duplicate check
- Final-grade distribution
- Study time vs final grade
- Absences vs final grade
- Gender-wise performance
- Parental education vs final grade
- Correlation analysis
- Outlier/anomaly check
- Seven visualizations

## How to run
Run:

`python CodeAlpha_Task2_Task3_Student_Performance.py`

The script creates a `visualizations` folder and saves seven charts there.
